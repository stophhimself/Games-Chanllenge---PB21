🎮 Power Game Analysis — Sales & Customer Insights Dashboard (Power BI) — PB21
📌 Project Overview
This Power BI dashboard analyzes game sales data from a fictional gaming company, focusing on customer demographics, order patterns, game category performance, regional revenue distribution, and time-based trends.
Designed as a comprehensive analytics portfolio project, it demonstrates advanced DAX modeling, time intelligence, geographic mapping, and business storytelling — ideal for showcasing skills in gaming industry analytics, retail, and consumer goods.

📐 Methodology
Data modeling: Star schema (Sales fact table + Clients, Games, Regions dimensions)
DAX measures include:
Total Revenue, Total Orders, Avg Customer Age
Revenue by Region, Revenue by Category
Time Intelligence (YTD, MoM, YoY)
Ranking functions for top products and customers
Use of interactive slicers for date, region, and category
Visual best practices: Consistent color scheme, clear labels, tooltips
🛠️ Tools & Technologies
Power BI Desktop
Intermediate–Advanced DAX (CALCULATE, SUMX, TIMEINTELLIGENCE, RANKX, SELECTEDVALUE)
Geospatial visualization (French regional map)
Dashboard layout & storytelling (multi-tab navigation, drill-through)
